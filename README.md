# NurseVerse — بنك أسئلة التمريض الحكومي (500 سؤال)

## التشغيل

1. افتح ملف `index.html` أو `Nursing_Government_Exam_500.html` بالنقر المزدوج في Chrome أو Edge أو Firefox.
2. اختر **ابدأ الامتحان**، ثم حدد المواد، وعدد الأسئلة، ونوع الجلسة (تدريب أو امتحان مؤقت).
3. في وضع التدريب يظهر التصحيح والشرح بعد الإجابة مباشرة. في وضع الامتحان المؤقت تظهر النتيجة والشرح بعد إنهاء الامتحان.

يعمل الموقع دون اتصال إنترنت؛ قد تحتاج الإنترنت لتحميل الخط الاختياري فقط. إذا لم يتوفر الخط، يستخدم خطًا احتياطيًا. جميع الأسئلة والإجابات موجودة داخل ملف HTML. لا يحتاج حسابًا أو خادمًا.

## وظائف الموقع

- 500 سؤال أصلي (MCQ) متعدد الخيارات، دون تكرار حرفي أو تكرار السؤال داخل الجلسة.
- Fundamentals (75)، Medical-Surgical (100)، Maternity (65)، Psychiatric (60)، Advanced/Critical (70)، Community (60)، Pediatrics (70).
- اختيار مجال واحد أو أكثر، و10/15/25/50/100/كل الأسئلة المتاحة.
- ترتيب عشوائي للأسئلة والخيارات، مع الاحتفاظ بترتيب الاختيارات ضمن الجلسة الجارية.
- تدريب بتصحيح فوري وشرح مختصر، أو اختبار مؤقت (90 ثانية لكل سؤال) دون كشف الإجابات حتى النهاية.
- نتائج تفصيلية، مراجعة الأخطاء، الأسئلة الجديدة فقط، الإشارات المرجعية والملاحظات، إحصائيات حسب القسم، البحث في الأسئلة.
- حفظ التقدم على الجهاز باستخدام `localStorage`، واستيراد/تصدير تقدم JSON، وتصدير نتيجة الجلسة CSV.
- التصميم متجاوب مع الحاسوب والهاتف؛ الواجهة بالعربية والأسئلة والشرح بالإنجليزية.

## المصادر والتوضيح العلمي

هذه أسئلة تعليمية **مكتوبة خصيصًا للموقع** مستوحاة من مبادئ NCLEX وموضوعات التوظيف في التمريض. **ليست أسئلة مسربة أو رسمية** من الحكومة أو من NCSBN. رُوعي الاعتماد على مبادئ سريرية معروفة، ولكن قد تتغير إرشادات الإنعاش والأدوية والتطعيمات، ويجب اتباع البروتوكولات الرسمية المطبقة محليًا.

المصادر العامة المستخدمة للاسترشاد:

- NCSBN 2026 NCLEX-RN test plan: https://www.ncsbn.org/publications/2026-nclex-rn-test-plan
- NCSBN Next Generation NCLEX sample format: https://www.nclex.com/prepare.page
- CDC Standard Precautions: https://www.cdc.gov/infection-control/hcp/basics/standard-precautions.html
- AHA 2025 Adult Advanced Life Support: https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/adult-advanced-life-support
- WHO PPH guidance 2025: https://www.who.int/news/item/05-10-2025-global-health-agencies-issue-new-recommendations-to-help-end-deaths-from-postpartum-haemorrhage
- SCCM Surviving Sepsis Campaign 2026: https://www.sccm.org/clinical-resources/guidelines/guidelines/surviving-sepsis-campaign-international-guidelines-for-management-of-sepsis-and-septic-shock-2026
- WHO suicide risk assessment: https://www.who.int/teams/mental-health-and-substance-use/treatment-care/mental-health-gap-action-programme/evidence-centre/self-harm-and-suicide/assessment-for-self-harm-suicide-in-persons-with-priority-mental-neurological-and-substance-use-disorders

## نشر الموقع

يمكن رفع `index.html` إلى استضافة ملفات HTML ثابتة (مثل GitHub Pages أو Netlify) في مشروع جديد؛ لا حاجة إلى قاعدة بيانات أو إعدادات خادم. التقدم المحفوظ في المتصفح لا يتزامن تلقائيًا بين الأجهزة؛ استخدم نسخة JSON الاحتياطية لنقله.

## جودة المحتوى

أجري فحص برمجي لعدد الأسئلة (500)، تفرد معرف كل سؤال وتفرد النصوص، وجود أربعة خيارات مختلفة لكل سؤال، وصحة تنسيق بنك الأسئلة. هذا الفحص ليس مراجعة علمية مستقلة لكل سؤال، لذا يجب مراجعة البروتوكولات المحلية عند الحاجة.

## التحديث الجديد — الاستكمال التلقائي بعد التحديث أو إعادة النشر على Vercel

**الميزة الجديدة:** بعد بدء جلسة وتمرير أو حل أي سؤال، يحفظ الموقع تلقائياً:

- رقم السؤال الحالي **ومعرّف السؤال** وبقية ترتيب الأسئلة ضمن الجلسة.
- الإجابات التي اخترتها، الأسئلة المنتهية، ترتيب الاختيارات وأداءك السابق.
- العلامات المرجعية والملاحظات والإحصائيات.
- الوقت المنقضي في الامتحان المؤقت؛ يمكنك استكمال الوقت المتبقي عند فتح الصفحة من جديد.
- إعدادات الاختبار: التخصصات، النمط، عدد الأسئلة وفلترة «الأسئلة الجديدة».

عند الضغط على **Refresh / F5** أو فتح الرابط من جديد، إن كان لديك اختبار غير مكتمل، يفتح التطبيق **نفس السؤال** آلياً وتظهر عبارة «محفوظ تلقائيًا». يوجد كذلك زر «استكمل من السؤال …» في الصفحة الرئيسية. جُهزت آلية حماية إضافية في المتصفح في حال تلف نسخة الحفظ الأساسية، وإصلاح للجلسات التي تحتوي على سؤال حُذف من الإصدارات اللاحقة.

**مهم: شرط الاحتفاظ بالتقدم عند نشر إصدارات جديدة:** يجب استخدام **نفس اسم النطاق (origin)** — مثال `https://my-nursing-site.vercel.app` — ونفس المتصفح والجهاز، مع عدم محو بيانات الموقع. لا تستخدم رابط معاينة Preview جديداً كل مرة، لأن كل نطاق يحتفظ ببيانات منفصلة. لا تنشئ مشروع Vercel جديداً لكل تحديث؛ حدّث **نفس المشروع**. عند تغيير النطاق أو الجهاز، صدّر ملف تقدّمك JSON من صفحة الإحصائيات واستورده في النطاق/الجهاز الجديد.

> إذا كنت بدأت الدراسة محلياً من ملف HTML ثم انتقلت للموقع على Vercel، لن ينتقل `localStorage` تلقائياً بين المكانين. استخدم تصدير / استيراد JSON لنقل تقدمك القديم.

### طريقة نشر الموقع مجاناً على Vercel (الأسلوب الأنسب للتحديثات)

1. فك ضغط ملف `NurseVerse_Vercel_AutoResume.zip`. ستجد `index.html` وملف التعليمات.
2. أنشئ Repository على GitHub، وارفع ملف `index.html` في الجذر.
3. افتح [Vercel Dashboard](https://vercel.com/new)، واستورد المستودع `Import Git Repository`، واختر **Other** إذا طُلب إطار عمل. لا تحتاج قاعدة بيانات ولا إعداد Build مخصّص لهذا الملف الثابت.
4. بعد النشر، افتح رابط المشروع الإنتاجي الثابت، مثل `https://YOUR-PROJECT.vercel.app`، وابدأ الدراسة.
5. عندما تريد إجراء تحديث جديد: **استبدل `index.html` داخل نفس مستودع GitHub واعمل Commit**، ليُنشر التحديث في نفس مشروع Vercel. افتح نفس الرابط الإنتاجي؛ سيعود الموقع لجلستك الحالية.

قد تُستخدم [Vercel Drop](https://vercel.com/docs) للنشر السريع، لكن ربط المستودع بـGitHub أسهل للحفاظ على نفس مشروع Vercel وإجراء تحديثات لاحقة.

```js

```

هذا مفتاح الحفظ نفسه المستعمل في الإصدار السابق؛ تغييره سيجعل المتصفح يبدو وكأن البيانات اختفت. يفضل كذلك إبقاء معرف السؤال ثابتاً (`id`) عند تغيير ترتيب الأسئلة أو تجديد واجهة التطبيق. إذا استُبدل سؤال بمحتوى مختلف جذرياً في تحديث قادم، يُفضل تخصيص معرّف جديد له لتجنب ربط سجل الإجابات القديم بسؤال جديد غير مطابق.

**حدود الميزة:** الحفظ محلي في المتصفح؛ لا يوجد تسجيل دخول أو مزامنة بين الأجهزة، وإزالة بيانات المتصفح أو استخدام التصفح الخفي قد تمحو التقدم. ننصح بتصدير نسخة JSON بشكل دوري.
